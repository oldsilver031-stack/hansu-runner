# 한수RunLearn 도트 러너 만들기

2026 청년 세계유산지킴이 한수RunLearn 팀의 부스 미니게임입니다.
한양도성을 달리는 나만의 도트 러너를 꾸미고, 러너 카드를 저장하고, 부스 러너로 등록해 다 함께 달릴 수 있어요.

- 옆모습 러너: 피부색 · 눈 모양 · 머리 길이/색 · 상의/하의 · 운동화 · 소품 선택
- 몸통 배번에 이름 · 번호 표시
- 러너 카드(1080×1350) 이미지 저장
- 등록한 러너는 이 기기의 브라우저에만 저장됩니다
